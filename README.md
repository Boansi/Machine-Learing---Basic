This repository documents my self-directed study of the fundamentals of Data Science and Machine Learning using Python.
The project was created as part of my effort to build a strong foundation in data analysis, data preprocessing, visualization, and introductory machine learning techniques. Through practical exercises and experimentation with real-world datasets, I gained hands-on experience with core data science libraries and workflows commonly used in machine learning projects.
Learning Objectives: Understanding the machine learning workflow, Learning how to prepare and clean datasets, Exploring and analyzing data and Visualizing data to gain insights
Libraries used: Numpy, Panda, Matplotlib and Jupyter
Future Learning golas: Scikit-learn, PyTorch and TensorFlow
